
# 🎵 音乐重命名工具 (Music Renamer)

一款简单易用的批量音乐重命名软件。它可以自动读取音频文件内部的标签信息（歌名、歌手），一键将乱码或毫无规律的文件名，整理成 `歌名 - 作者` 等标准格式。

## 📥 下载与运行

1. 点击本页面右侧的 **[Releases](../../releases)** 标签。
2. 在最新版本下方，下载 `音乐重命名工具.exe` 文件。
3. 下载完成后，直接**双击运行**即可（软件为绿色免安装版，无需安装 Python 环境）。

> 💡 **提示**：如果双击后 Windows 弹窗提示“Windows 已保护你的电脑”，请点击“更多信息” -> “仍要运行”。（这是因为个人开发者未购买数字签名证书导致的常规安全拦截，请放心使用）。

## 📖 使用教程

软件界面非常直观，只需简单四步即可完成批量重命名：

1. **选择输入文件夹**：点击「浏览…」，选择存放乱码或待处理音乐的文件夹。
2. **选择输出文件夹**：点击「浏览…」，选择重命名后的文件要保存到哪里（如果不选，默认保存在原文件夹下的 `renamed` 文件夹中）。
3. **选择命名规则**：在下拉菜单中选择你想要的格式，默认是「歌名 + 作者」（例如：`晴天 - 周杰伦.mp3`）。
4. **扫描与执行**：
   - 点击 **「🔍 扫描预览」**，软件会自动读取音乐信息，并在列表中展示“原文件名”和“新文件名”，请先核对确认。
   - 确认无误后，点击 **「▶ 开始重命名」**，等待绿色进度条跑完即可！

## ✨ 核心特性

- **支持多种格式**：完美支持 `.mp3`、`.flac`、`.m4a`、`.wav` 等主流音频格式。
- **安全防覆盖**：如果遇到重名文件，软件会自动在后面加上 `(1)`、`(2)` 等后缀，**绝对不会覆盖你的原文件**。
- **多种处理方式**：你可以选择将重命名后的文件“复制”到新文件夹（保留原文件），也可以选择“移动”（相当于原地修改）。
- **标签缺失保护**：如果音频本身没有内置歌曲信息，软件会自动跳过并标注，不会乱改名字。

## ❓ 常见问题

**Q：为什么部分文件没有被重命名？**
A：这可能是因为该音频文件内部缺少“歌名”或“作者”标签。软件无法凭空获取信息，所以为了保护文件，会自动跳过这些无标签的音频。

**Q：软件处理速度有点慢？**
A：由于需要逐个读取文件的底层标签信息并进行拷贝，处理大量文件时需要一点时间，请耐心等待进度条走完。

**Q：支持 Mac 或 Linux 吗？**
A：目前仅提供 Windows 版本的 `.exe` 成品。
